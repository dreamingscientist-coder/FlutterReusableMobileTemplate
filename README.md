# FlutterReusableMobileTemplate

A reusable Flutter starter template for iOS and Android apps.
Clone it, rename it, and start building your own app faster.

## Project structure

| Folder / File | Purpose |
|---|---|
| `lib/` | Main app source code (Dart) |
| `assets/` | Images, fonts, and other resources |
| `test/` | Automated tests |
| `docs/` | Documentation |
| `setup/` | Setup scripts and instructions |
| `tool/` | Helper scripts for development |
| `release/` | Release and publishing notes |
| `Makefile` | Shortcut commands for common tasks |
| `pubspec.yaml` | Flutter dependencies and app settings |

## Getting started

1. Clone this repo:
   ```bash
   git clone https://github.com/dreamingscientist-coder/FlutterReusableMobileTemplate.git
   ```
2. Install packages:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```
